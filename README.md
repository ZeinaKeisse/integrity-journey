# The Integrity Journey

**From Assignment to Submission** — an interactive guide to academic integrity for first-year undergraduate students.

**Live site:** https://zeinakeisse.github.io/integrity-journey/

## What it is

The Integrity Journey follows one essay from the day it is assigned to the day it is submitted. Across seven stops, students make the practical decisions that academic integrity actually involves, and collect a stamp at each stop:

1. **Assignment** — six values before writing begins
2. **Research** — quoting, paraphrasing, and common knowledge
3. **First Draft** — recognising copied wording
4. **AI Assistance** — building a disclosure statement
5. **Under Pressure** — naming risky shortcuts
6. **Crossroads** — okay, not okay, or ask first
7. **Submission** — seven checks before submitting

Completing all seven unlocks a certificate of participation that can be printed or saved.

## How to use it

Open the live site in any modern browser, or download `index.html` and open it locally. Everything runs in a single file with nothing to install. Progress is saved in the browser, so students can return to unfinished stops.

Instructors are welcome to link to the site from a course page or embed it in a learning management system with an `<iframe>`. Students should always check their own institution's academic integrity policy and course syllabus; the scenarios here are illustrative, and expectations differ between courses.

## Accessibility

The site is built with semantic HTML, keyboard navigation, screen-reader labels, visible focus states, and reduced-motion support, so it can be adapted to the accessibility needs of its audience in line with the AODA and the Accessible British Columbia Act.

## How it was made

The site was created as a single-file HTML artifact for the *Playing with Design* assignment at the University of British Columbia. Generative AI was used to support brainstorming and code generation; the creator directed the design, reviewed all content, and takes responsibility for the final work. A supplementary version of the journey was also explored in Genially.
